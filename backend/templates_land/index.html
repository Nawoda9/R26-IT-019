About this tool

This runs a YOLO11 model (models/best.pt) trained to detect palm/coconut trees, then:

  • Draws bounding boxes + confidence for every detected tree
  • Estimates land utilization (circle-buffer approximation) and a density heatmap
  • Segments actual canopy pixels (Excess Green Index) for a pixel-accurate empty-space map and candidate planting pockets
  • Runs a greedy, spacing-aware algorithm to estimate how many new trees can realistically be planted

A JSON API is also available at /api/analyze - see /api for details.
