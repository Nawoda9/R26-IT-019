# PP1 Integration Plan

At PP1 stage, each member's component is developed separately but maintained inside one shared GitHub repository.

## Components

1. AI-Based Image Classification System for Coconut Germplasm Identification
2. GIS-Driven Land Utilization Analysis for Coconut Gene Banks
3. Crowdsourcing-Based Community Intelligence Platform
4. WCLWD Severity Assessment Framework

## Current Integration Plan

- One shared GitHub repository
- Common folder structure
- Separate backend folder for each component
- Separate model folder for each component
- Common frontend dashboard with four component cards

## Frontend Integration

The main dashboard will display four cards. Each card will open the relevant component page.

## Backend Integration

Each member will expose APIs from their backend. The common frontend will call each backend API based on the selected component.

## Final Integration

After PP1, all components will be connected through APIs and displayed in one unified system.
